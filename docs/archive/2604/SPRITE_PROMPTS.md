## Notes for Nano Banana

1. **Transparent background is mandatory** — every image must have clean alpha channel, no background
2. **Consistent character design** — same face, hair, outfit, proportions across ALL 26 images. Provide the official game artwork as the anchor reference
3. **Half-body composition** — show from chest/upper torso up, head centered in frame
4. **512×512 PNG** — square canvas, character centered, leave some padding at edges
5. **3/4 view angle** — slight left-facing angle for all frames (consistent direction)
6. **Frame-to-frame variation should be subtle** — only expression and minor pose changes between frames of the same emotion. Do NOT change clothing, hair, or camera angle between frames
